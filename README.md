# 📄 Convertidor SRI a Excel - Ecuaplus

Una herramienta web simple y segura para **convertir los reportes de texto (.txt) del SRI** (Servicio de Rentas Internas de Ecuador) a formato **Excel (.xlsx)**, completamente en tu navegador.

## 🚀 ¿Qué hace?

Toma los archivos de "Comprobantes Recibidos" o reportes similares en formato de texto plano (TSV/TXT) que descarga el sistema del SRI, y los transforma en una hoja de cálculo limpia, organizada y con los números formateados correctamente para que puedas trabajar de inmediato.

### ✨ Características Principales

- **⚡ 100% Privado:** Todo el procesamiento ocurre en tu navegador. **Tus datos nunca salen de tu computadora.**
- **🖱️ Drag & Drop:** Simplemente arrastra tu archivo `.txt` y listo.
- **📊 Cálculos Automáticos:** Genera totales de Base Imponible, IVA e Importe Total automáticamente.
- **🛠️ Corrección de Formatos:** Soluciona problemas comunes de puntos y comas en los números del SRI.

## 🛠️ Tecnologías Usadas

Este proyecto no requiere instalación de servidores ni bases de datos complejas. Está construido con tecnologías web modernas y librerías ligeras:

- **HTML5 & CSS3**
- **[Tailwind CSS](https://tailwindcss.com/):** Para el diseño moderno y responsivo.
- **Javascript (Vanilla):** Lógica pura sin frameworks pesados.
- **[SheetJS (xlsx)](https://sheetjs.com/):** Para generar el archivo Excel.
- **[PapaParse](https://www.papaparse.com/):** Para leer los archivos de texto correctamente.

## 📦 Cómo Usar

No necesitas instalar Node.js, Python ni PHP.

1.  **Descarga** este repositorio (o los archivos `index.html`, `styles.css`, `script.js`).
2.  Haz doble clic en el archivo `index.html`.
3.  Se abrirá en tu navegador favorito (Chrome, Edge, Firefox).
4.  ¡Arrastra tu archivo del SRI y descarga tu Excel!
